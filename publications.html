✦ New · 2025 IEEE SSCS Code-a-Chip Award Travel Grant · ESSERC 2026
Power Side-Channel Vulnerability Analysis on Analog In-Memory Computing Arrays
T. Das, U. Singh  ·  Co-authored
IEEE SSCS Code-a-Chip Design Challenge · ESSERC 2026, Palma de Mallorca, Sep 7–10
Pearson ρ = 0.9979 (HW leakage) ρ = 0.9998 (weight extraction)
Demonstrates power side-channel vulnerability on analog in-memory computing (IMC) arrays — RRAM 1T1R crossbar architecture on SKY130 PDK using Ngspice. Achieves Pearson ρ = 0.9979 for Hamming weight leakage and ρ = 0.9998 for weight extraction from power traces. Awarded IEEE SSCS Code-a-Chip Travel Grant for presentation at ESSERC 2026, Palma de Mallorca.

✦ New · Accepted ESSERC 2026 Neuromorphic Computing
Frequency-Encoded STDP Learning Using 3-Terminal PCMO RRAM Synapses in a 16×3 Crossbar
T. Das, U. Singh et al.
IEEE European Solid-State Electronics Research Conference (ESSERC 2026) · Palma de Mallorca, Sep 7–10, 2026
92.6% Iris accuracy 180nm TSMC · Cadence Virtuoso
Demonstrates frequency-encoded spike-timing-dependent plasticity (STDP) learning using 3-terminal PCMO RRAM synapses in a 16×3 crossbar array. Fabricated in 180 nm TSMC technology using Cadence Virtuoso. Achieves 92.6% classification accuracy on the Iris dataset using neuromorphic learning without backpropagation. Accepted for ESSERC 2026, Palma de Mallorca.
