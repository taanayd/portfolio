4 action modes ↓
Portal Workflows

4 action modes

Mode 01
List CRs
Queries Jira only — shows all Verifier Assigned CRs with title and status. No files touched. Safe for triage.
Mode 02
Setup (No-Run)
Creates directories, copies bugcase files, generates produced_run.sh via AI — does not execute. Inspect before running.
Mode 03
Execute
Full run: setup + execute on LSF or locally. Generates HTML + CSV report. Shortcut: Ctrl+Enter.
Mode 04
Execute Live
Same as Execute but streams every log line live via WebSocket. Ideal for debugging individual CR failures.
